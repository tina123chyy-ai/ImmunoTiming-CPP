# 演示实验报告（预运行示例结果）

## 研究目的

用C++数值实现三变量概念性微分方程模型，并检查在假设参数和任意治疗输入下，不同策略会产生怎样的计算轨迹。**本报告不研究真实临床效果。**

## 参数与方法

- 初始状态：`T=0.25, C=0, E=0`
- 时域：0至40个任意模型时间单位
- 微分方程求解：RK4，步长0.05
- 给药输入：矩形脉冲，默认疫苗从第2模型时间单位开始，CAR-T从第10开始
- 所有速率参数均为假设且归一化的演示值（见`include/TumorModel.h`）

## 四种策略：本示例输出

下表来自仓库预运行的`results/baseline/summary.csv`。数字不是患者结果，不可据此推断真实疗效。

| 示例策略 | Tumor AUC | 最终模型肿瘤负荷 |
|---|---:|---:|
| 无治疗 | 30.807 | 0.993 |
| 仅疫苗 | 27.880 | 0.982 |
| 仅CAR-T | 9.904 | 0.171 |
| 联合治疗 | 9.096 | 0.181 |

有趣之处是：**在这个特定模型、参数和时间安排下**，联合治疗的累计肿瘤负荷更低，但结束时的肿瘤负荷并不比仅CAR-T更低。这提示“哪个方案更好”还取决于采用何种评价指标，不能简单将四条曲线归结为固定的临床排序。

## Top-K调度（示意性，非临床时间建议）

项目比较多个疫苗与CAR-T开始时间的网格组合，通过目标函数

`objective = tumor_auc + 0.5 * final_tumor`

进行数学排序。该函数是人为选择的，不包括任何毒性、安全性或现实可行性因素。示例中排名最前的候选方案可能出现CAR-T早于疫苗的情况，**这只说明在这个模型和评分下，较早控制肿瘤负荷的方案可能占优势，不说明真实治疗应该如此安排**。

## 参数敏感性

`results/sensitivity/sensitivity.csv`比较16组反馈系数`beta`和协同系数`gamma`的组合。它体现结果如何依赖事先设定的正向反馈关系，仍不能验证这些关系在实际人体内发生的强度。

## 本项目最有学术价值的反思

1. 图像变为C++实际计算结果之后，示意性预期与数学方程求解之间的差别可以被明确检查。
2. 将已学习的微分方程转化为一个可以重复运行的程序，要求明确时间步长、输入事件和边界条件。
3. 假设参数、评分指标和省略的生物机制都会影响结果。
4. 科学严谨性不仅是得出一条曲线，还包括说清楚这条曲线能与不能支持哪些结论。
